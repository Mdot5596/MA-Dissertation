Environmental Guidance in Level Design

This executable contains three playable prototypes investigating environmental techniques for guiding player navigation.

Requirements:
Windows 10/11 64-bit
Microsoft Visual C++ 2015–2022 Redistributable (x64)

link to the Downloadable exe ---- https://drive.google.com/file/d/1M0St56vyDbylVVpb14xPRH3ysQ-5gZpl/view?usp=sharing

Unzip and open folder, Find the file named MyProject.exe and double click it to run

Prototype 1 — Lighting
Investigates how lighting and visual contrast can influence player movement.

Prototype 2 — Architectural Guidance
Investigates how environmental layout and spatial configuration can influence navigation.

Prototype 3 — Landmarks
Investigates how recognisable environmental landmarks can support player orientation.

Controls:
WASD — Movement
Mouse — Look
E — Interact
ESC — Return to Main Menu
